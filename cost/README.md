# 100-review cost & runtime calculator

Input: `assignment/cost_100.csv` (unchanged; first 100 rows of checkpoint_500; SHA-256 `c884ac3b9be5066995d5063f96ad9af6e5e082975788c1684c4f6b6ea661dd0e`, matches `manifest.json`).

| file | content |
|---|---|
| `pilot_records.jsonl` | one status/record per pilot ID (grading-contract fields, original row hash) |
| `pilot_calls.jsonl` | every attempted call, cold run (`run_id: cold`) and warm run (no enrichment calls); request IDs, usage, latency, cost |
| `usage.csv` | raw provider usage per call (uncached input, cache read/write, output tokens) |
| `rates.csv` | **editable** dated prices per million tokens + official source links; Batch multiplier |
| `scenario.json` | **editable** budget, output-token cap, max workers, fallback fraction/model, retry rate, parallel efficiency, verify sample size, conservative overrides |
| `summary_cold.json`, `summary_warm.json` | per-stage wall-clock and counts |
| `measurements/` | 500- and 10,000-review checkpoints + the full run: per-review token usage refresh |
| `report.md` | measured-100 tables, full-run projections, budget warnings (regenerated by `replay --write`) |

## Offline replay (default; no API key, no network)
```bash
python3 cost/calculator.py replay --write
python3 cost/calculator.py replay --rate-multiplier 2      # doubles API rates: API subtotal exactly doubles; time/local compute unchanged
python3 cost/calculator.py replay --budget 5 --workers 8 --fallback-fraction 0.02 --output-cap 30
```
Importing the module never makes a paid call. Cost = billed units × price per unit for each mutually exclusive item (uncached input, cache read, cache write, output; Batch rows × `batch_multiplier`). Local compute/electricity is **unknown (not measured)** and is never silently zero.

## Explicit paid pilot (needs `ANTHROPIC_API_KEY`; ≈ $0.01–0.02)
```bash
python3 cost/calculator.py pilot --confirm-paid     # empty result cache, 1 worker: cold run, then warm run on the saved cache
```
Retry/spend/recovery controls demonstrated: `evals/system_tests.json` (transient failure retried, spend cap stops dispatch, malformed output retried once then quarantined) and the interruption/resume recording in `evals/interruption/`.
